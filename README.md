### 🚀 Proyecto destacado

#### [TFG-ASIR-SOC-Wazuh-Nut-Sai](https://github.com/javiergithubb/TFG-ASIR-SOC-Wazuh-Nut-Sai)

SOC/SIEM centralizado desplegado sobre Proxmox VE:

- Reglas XML personalizadas para accesos fuera de horario y fuerza bruta, con **respuesta activa** (`firewall-drop`).
- Alertas críticas automatizadas con **Python** y la **API de Telegram**.
